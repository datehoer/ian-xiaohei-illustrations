# 中国自助洗烘店：数据与下一版视频方案

后续状态：两版视频已制作，成片与实现说明见 [多镜头视频 v2](video-v2.md)。下文保留制作前的接口测试与方案记录。

记录日期：2026-09-11。主题为「一家洗衣店一年到底能赚多少」，用户已确认中国自助洗烘店，沿用试片角色与画风。城市尚未确定；以下上海资料仅用于接口和取证流程测试。

建议先建立一份经过核查的案例账本，再做 60–90 秒短片和约 10 分钟详细片。时长、镜头数量是制作建议，尚未生成新版成片。上一版 41.4 秒视频中的数字仍然全部是演示假设，不因本轮查到部分资料而变成真实门店数据。

## 搜索接口实测

使用用户指定的 `https://api.hotday.uk/v1`，模型列表存在 `grok-chat-fast`。一次 `chat/completions` 调用成功，耗时 49.38 秒，返回模型名相同，正常结束。响应含 2 条结构化 URL 引用；另有正文中的厂商网址。没有返回可供检查的搜索工具调用事件，因此只能确认接口成功并返回可核对来源，不能仅凭模型自述确认它内部如何搜索。

原始请求、回答和元数据保存在被 Git 忽略的 `outputs/research/grok-search-test/`。请求凭据由隐藏输入提供，没有写入文件。本次测试只能评价这一份回答，不能得出整体准确率。

| 项目 | 原页核对结果 | 允许如何使用 |
|---|---|---|
| 上海最低工资 | [人社局通知](https://rsj.sh.gov.cn/tgzfl_17732/20250714/t0035_1434097.html)载明自 2025-07-01 起月标准 2,740 元、小时标准 25 元；月标准有社保、公积金等排除项 | 有明确日期的政策证据；尚未确认截至制作日是否有后续调整，且不能当作实际招聘工资或雇主全部人工成本 |
| 浦东部分供水区域非居民水价 | [区属供水通知](https://www.pudong.gov.cn/zwgk/qtzcxwj-fgwzcwj/2023/319/319884.html)载明自 2023-12-01 起综合水价 5.99 元/立方米；供水 3.32 元，污水处理征收标准 2.97 元，后者按用水量的 0.9 计收 | 先核实门店供水区域、类别和最新账单；不能将标准直接相加为 6.29 元，也不能当作全国水价 |
| 水价日期错误 | 回答将市属同类标准描述为同步；[市属通知](https://www.shanghai.gov.cn/gwk/search/content/330e7a5a888446d5b474119bda9cf1e4)对应生效日期为 2021-09-15 | 修正地区与生效日期后使用；金额相同也不代表适用范围和日期相同 |
| 设备耗水 | [ARI 厂商规格页](https://zh-cn.ari-cn.com/product/xgq-series-automatic-washing-machine-washer-extractor/)有 XGQ-25F 的 25 kg 容量及每循环 387 kg 耗水等参数 | 原页存在该规格；工业洗衣设备尚未与案例门店匹配，不进入基准成本。额定功率 kW 不能当成单次耗电 kWh |
| 实际门店收费 | 本次未取得可核验的近期门店价目表；回答提及无出处旧案例 | 暂不采用，继续获取真实门店价格或保留为明确假设 |

结论：用搜索模型发现线索，再直接检查原页、适用对象和日期。回答有引用也需要核查；不能自动把搜索回答中的数值填入账本。

## 怎样拿到可用数据

正式片聚焦一个城市、一类商圈、一个配置明确的门店案例。即便取得真实账本，也只代表这个案例，不能推出全国自助洗烘店平均利润。

| 所需数据 | 优先证据 | 关键口径 |
|---|---|---|
| 洗衣、烘干成交价 | 门店官方价目、下单页、实际消费记录 | 容量、时长、正常价与优惠价；洗衣和烘干分别记录；充值现金不直接当作当期营业收入 |
| 订单量与季节变化 | 经允许提供的订单后台、月度结算；必要时多时段现场观察 | 区分用户、订单、机器循环；观察样本只能说明观察时段，机器最大产能不能代替实际需求 |
| 房租、物业和改造 | 案例租约、物业账单、具体商铺报价 | 挂牌价与签约价分开；面积、位置、排水、排风、电力容量条件一致 |
| 水、电、燃气、耗材 | 当地官方费率、实际账单；对应机型说明书和实际程序测试 | 商业或居民类别、峰谷、加价、程序温度、负载、烘干方式；烘干不可一律按电费估算 |
| 设备投资与维护 | 明确型号的报价、安装合同、维护账单 | 含税、运输、安装、质保范围、停机损失；设备价不等于全部开店投入 |
| 人工与店主时间 | 实际排班、工资与清洁维护记录 | 自助不等于无人工作；工资、用工附加成本和店主劳动只计一次 |

没有门店后台时，客流采用保守、基准、较高三档假设，直接显示「情景测算」。没有来源的数字不标「行业均值」。短片可以先讲达到多少洗烘循环才能打平，避免假装已经知道所有门店一年赚多少。

每条准备进稿的数字记录：数值或范围、单位、来源 URL/文件、发布日、生效日、地区、机型或业态、含税口径、核验状态、允许用途。核验状态区分「原页已核对」「有条件适用」「待核验」「演示假设」。动态价格和政策在定稿时复查。

## 账本应怎样计算

- 年收入 = 各容量洗衣成交价 × 对应年度循环数 + 各档烘干成交价 × 对应年度循环数 + 其他明确收入。先明确是否采用不含增值税口径，并保持收入和成本一致。
- 洗衣与烘干分别扣单次变动成本；以洗衣循环为锚点时，单独声明平均附带烘干循环数。不要默认每位客人都购买等价的洗烘套餐。
- 年税前利润 = 年贡献毛利 − 固定运营成本 − 折旧 − 利息。每个成本只扣一次；维修与耗材按实际合同和发生方式分类。
- 店主工资若已计人工，不再扣第二遍。经济测算中即使店主未领工资，也单列其劳动价值及处理方式。
- 单位组合稳定且贡献毛利为正时，可推算盈亏平衡循环数；改动烘干附带率、折扣或容量组合后重算。
- 展示税前利润、店主获得的工资和现金流时分别命名。回本需要考虑初始现金投入、押金、营运资金、税、设备更新和融资偿还，不能拿税前利润直接冒充回本现金。
- 年度模型体现淡旺季、停机和开业爬坡，不用一个旺季周末乘全年。

## 短片与长片

| 项目 | 60–90 秒短片 | 约 10 分钟详细片 |
|---|---|---|
| 观众得到什么 | 看懂一个条件明确的年利润结果，以及客流下降如何改变结果 | 看懂开店投入、单次贡献、年度利润、回本与经营难点 |
| 内容组织 | 提问 → 案例条件 → 一笔洗烘 → 简账 → 客流敏感性 → 回答标题 | 同一份底稿，展开成本依据、经营机制、淡旺季与多个情景 |
| 建议画面数量 | 8–12 张独立插图，约 12–18 个有效镜头 | 30–40 张独立插图，加数据图和细节镜头，共约 55–70 个镜头 |
| 画面节奏 | 通常 4–6 秒出现新的信息或动作 | 通常 8–12 秒换镜头；复杂账表留足阅读时间，过程中逐项出现 |
| 建议画幅 | 首轮沿用 16:9 便于比较；投放竖屏平台时另排 9:16 | 16:9 |

独立插图数量不等于镜头数量。用同一张图更换字幕不算一个新的插图镜头；特写、比较、数据揭示必须带来新的信息。上述节奏是剪辑目标，不是每隔几秒强制闪切。

长片可按以下时间预算写稿，最终由配音实测调整：

| 时间 | 主要内容 |
|---|---|
| 0:00–0:30 | 标题问题、案例边界与关键悬念 |
| 0:30–1:30 | 谁来洗衣，门店提供什么，订单从哪里来 |
| 1:30–3:00 | 设备、租赁、改造及运营缓冲 |
| 3:00–5:00 | 跟着一笔洗烘拆收入和变动成本 |
| 5:00–6:30 | 年账、人工及店主时间 |
| 6:30–8:30 | 淡季、低客流、折扣、停机的情景变化 |
| 8:30–9:30 | 利润与现金流、回本的区别 |
| 9:30–10:00 | 回答标题，重申案例条件 |

试片测得约 175 个汉字/分钟，只能作为当前音色和文本的粗略参考。长片初稿可从约 1,800–2,100 个口播汉字起步，数字读法和停顿会改变时长；再按真实 TTS 音频调整到约 10 分钟，不能用字数强行认定时长。

## 左侧配图如何更灵活

试片开场图连续停留约 14.4 秒、成本图约 16.4 秒。下一版用内容推动画面变化，同时让角色和画风保持一致：

1. 门店全景：柯基搬洗衣篮进店，交代顾客和机器。
2. 操作特写：投衣、付款、选程序，让一笔交易可见。
3. 机制画面：洗衣桶、水表、电表或燃气烘干，解释钱花在哪里。
4. 劳动画面：清洁绒毛过滤器、处理故障、整理店面，说明自助店的隐形工作。
5. 对比画面：周末排队与工作日空机、正常营业与故障停机。
6. 全屏账表：需要算账时释放整屏空间，逐项扣除成本；随后回到场景。

不固定整片左图右表。穿插全景、细节、左右对比和全屏数据；轻微推拉可辅助衔接，但不把推拉当成场景更新。中文数值仍由程序绘制，避免让生成图片承担精确财务文字。

## 制作顺序与程序差距

推荐顺序：确定案例与证据 → 校核三档账本 → 短片口播和分镜 → 小段配音/换镜节奏验证 → 短片成片 → 同底稿扩展长片。先解决数据口径与画面节奏，再投入整部长片的配音和插图。

现有程序已能生成语音、静态图卡、字幕和视频；搜索测试仍是独立实验，没有接成自动事实审核系统。下一版需要把旁白段落、字幕段和画面镜头分开建时间轴，支持一段自然口播切多个画面，并补充多种布局。较长段落的字幕需要时间戳或音频对齐，不能继续依靠每句话单独生成 TTS 来驱动所有切镜。

本文件记录研究结论和建议；上述多布局、独立镜头轨及新版短长片尚未实现。
