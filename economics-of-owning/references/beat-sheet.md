# Beat sheet 与包装

## 时间轴（14 分钟默认）

| 段 | 时间 | 任务 | 口播感觉 |
|---|---|---|---|
| Hook | 0:00–0:35 | 想象 vs 数字 | 冷，快 |
| 拆神话 | 0:35–2:00 | 失败率 + 你真正在卖什么 | 拍醒 |
| 启动成本 | 2:00–4:00 | 分项区间 | 重量 |
| 单位锚点 | 4:00–7:00 | 一笔交易从定价拆到口袋 | 全文高潮 |
| 隐藏费用 + 劳动力/位置 | 7:00–10:00 | 锚点上再刮几层 | 烦、真实 |
| 年账 | 10:00–12:00 | $X 营收怎么变成 $Y | 结算 |
| 失败与规模 | 12:00–13:20 | 单店是工资 | 收束 |
| 回收 | 13:20–14:00 | 同一句开场回来 | 停 |

短版 8 分钟：合并隐藏费用与年账，规模化只留 4 句。

## 开场公式


Okay, so you want to own a [X].
[三件浪漫道具，逗号连起来]。
Sounds like [好日子的一句话]。
Here's the thing.
[失败率或反直觉利润]。


中文对应：


所以你想拥有一家[X]。
[道具 A]，[道具 B]，[道具 C]。
听起来像一种像样的生活。
但账不是这么算的。
[失败率]。


## 锚点公式

选观众能在脑子里看见的一笔交易。

- 咖啡馆 → $5 latte
- 洗衣店 → $4.50 一筒烘干
- 洗车店 → $18 基础洗
- 仓储 → $165 一间小仓月租
- 健身房 → $49 月卡

拆法（必须按这个顺序写，不要跳）：

1. 标价
2. 直接物料 / 能耗 / 耗材
3. 毛利率（这里要故意让它看起来很美）
4. 人工摊入
5. 房租摊入
6. 手续费、损耗、折旧、保险
7. 这一笔真正剩下多少，百分之几

一句收束：「看起来是 80% 的生意。装进一整家店，它不是。」

## 年账公式（必须出现）

给定一个「看起来不错」的年营收。然后按行业常识切块：

- COGS / 变动成本
- 人工（通常 25–40%，重服务更高）
- 租金/占用（目标 6–12% 营收，超了标红）
- 手续费 1.5–3.5%
- 软件订阅、保险、维修、损耗
- 税前净利
- 店主再给自己开工资之后还剩什么
- 折算店主时薪（按 60–70 小时周）

结尾对比：员工时薪 vs 店主时薪。不要煽情，并排放着。

## 标题

好奇心：The Economics of Owning a [X]（本家，优先）
SEO：How Much a [X] Actually Makes
情绪：Why a Busy [X] Can Still Go Broke

中文：
- 拥有一家[X]的经济学
- 一家看起来很忙的[X]，老板能剩多少
- [锚点标价]里，有多少进你口袋

## 缩略图

五选一即可拍摄/生成：

1. 锚点物件特写 + 标价 + 划掉后的真利润
2. 热闹店面 vs 空荡后台
3. 机器特写（咖啡机/洗衣机/洗车龙门）+ 美元数字
4. 队列很长 + 角落一个很小的净利润百分比
5. 合同/租金支票压在产品照片上

文字不超过 4 词。黑、白、琥珀、冷灰。不要笑脸出镜。

## 分镜密度

- 口播每 8–15 秒换画面
- 数字出现时切图卡，不要只靠旁白
- 机器、柜台、排队、空桌、水电表、POS 屏幕轮换
- 禁止连续 20 秒同一张库存咖啡馆微笑图
