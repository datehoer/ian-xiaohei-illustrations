# 数字口径

## 原则

- 用区间，不装精确到个位的假调研。
- 写「典型美国独立店 2024–2026 量级」，不要假装审计过某家店。
- 同一稿的数字必须自洽：单位贡献毛利 = 单价 − 单位变动成本；单位贡献毛利 × 年交易笔数 − 年固定成本 − 折旧 − 利息 = 年税前利润。若单位利润已摊入固定成本，不能再重复扣除。店主劳动只计一次，并明确人工是否已包含店主工资。
- 找不到可靠公开数字时，明确写「演示假设」并列出假设，不得将无来源数字包装成「行业常见区间」。事实、行业统计与假设模型分开。
- 品牌案例只用公认公开事实（成立年、从一间店到被收购/上市的轮廓），不编单店利润。

## 常用锚（可被当地市场覆盖）

这些是未核验的写作参考，不能直接进入正式稿。使用前需核实来源、地区、年份、业态与分母；没有来源则删除该说法或改为明确的假设案例。用户指定城市则按当地租金重算。「关店」「失败」「易主」不能混作同一统计指标。

| 项目 | 常见量级 |
|---|---|
| 独立小店失败/易主 5 年 | 约 50–70%，视业态 |
| 饮品毛利率 | 70–85% 看起来很美 |
| 净利率（管得好的独立店） | 常在 5–15% |
| 租金占营收 | 舒适区 6–10%，警戒 12%+ |
| 人工占营收 | 25–40% |
| 刷卡费 | 1.5–3.5% |
| 回本 | 3–6 年量级，不是 12 个月 |

## 启动成本写法

永远给低–高区间，并拆 6–8 项：

装修/改造、押金+首尾月租、核心设备、家具、证照、初始库存、POS/软件、3–6 个月运营缓冲。

点出「缓冲」：很多店不是死在开业，是死在前六个月还没打平的时候。

## 禁止

- 伪造具体公司内部利润表
- 用一个网红店的房租当全国均值
- 把连锁摊销后的净利率安在独立店头上
- 为了刺激把失败率写成 90% 又给不出口径
- 同一段里 $5 成本结构加总对不上标价
