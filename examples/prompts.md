# 使用示例

同一个 `$ian-xiaohei-illustrations` 入口支持角色设计与内容配图。已有角色时直接沿用，不重新选型。

## 用默认柯基生成内容图

```text
Use $ian-xiaohei-illustrations 为下面的口播生成 4 张配图。
沿用极简线描拟人柯基，16:9 白底，底部留字幕区。
解释镜头加必要的短引线标注，文字与对应物件一一对齐。

口播：
听起来机器自己转，钱自己进盒子。但账不是这么算的。
收入还要承担水电、房租、维修和还贷。
```

## 只做分镜

```text
Use $ian-xiaohei-illustrations 先不要生图。
把这篇文章拆成约 5 个镜头，每镜写出核心意思、画面动作、
角色是否出场、标注文字、引线目标，以及哪些数字适合后期叠加。
```

## 设计新角色

```text
Use $ian-xiaohei-illustrations 以我附的角色图片为身份参考，
生成 3 个适合科普视频的拟人角色方向。
保留主要识别特征，用同一个动作对比画风。
```

## 换动作，沿用角色

```text
Use $ian-xiaohei-illustrations 沿用默认柯基，
生成它蹲下来修洗衣机的画面。
标注“坏了你修”用红色引线指向维修部位。
不要带入角色参考图里的账单和计算器。
```

## 修改引线

```text
Use $ian-xiaohei-illustrations 修改这张图：
把“还得算账”的引线端点接到计算器边缘，其他内容保持不变。
```

## 可选原版小黑

```text
Use $ian-xiaohei-illustrations 这次改用原版小黑，
为“想法要经过约束才变成可测试的方案”生成一张手绘配图。
```
