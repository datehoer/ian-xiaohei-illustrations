# 口播手绘配图 · 柯基版

将口播或文章中的场景、机制和转折变成连贯的手绘配图。一个入口包含角色设计与内容配图两种模式；角色档案与参考图独立保存，内容模式直接复用已选角色。

本 fork 保留 `ian-xiaohei-illustrations` 名称和调用方式。默认角色为 [极简线描拟人柯基](references/characters/corgi-minimal.md)，用户可以指定其他角色。画风、角色身份、叙事道具和标注分别控制。

角色选择顺序：本次用户明确指定的角色 → 当前项目已选角色档案 → 内置柯基。项目角色与参考资产的保存方式见 [角色设计](references/character-design.md)。

## 任务路由

只读取本次任务所需的参考，不把角色探索当成每次配图的前置步骤。

| 用户任务 | 参考 | 输出方式 |
|---|---|---|
| 设计主角、替换角色、比较画风 | [角色设计](references/character-design.md)、[风格](references/style-dna.md) | 讨论时给方案；明确要求生图时生成候选，选定后保存角色档案和参考图。 |
| 只做分镜、shot list、分析哪里配图 | 当前角色档案、[构图](references/composition-patterns.md)、[标注](references/annotations.md) | 输出分镜和标注计划，不调用图像模型。 |
| 生成单图或一组内容图片 | 当前角色档案、[风格](references/style-dna.md)、[构图](references/composition-patterns.md)、[提示词](references/prompt-template.md)、[标注](references/annotations.md)、[QA](references/qa-checklist.md) | 直接按已明确方向逐张生成，默认使用已选柯基。 |
| 编辑现有图片 | [提示词](references/prompt-template.md)、[QA](references/qa-checklist.md) | 明确编辑目标与保留项，优先局部修改。 |
| 明确要求原版小黑或上游样例 | [小黑可选角色](references/xiaohei-ip.md)、[构图](references/composition-patterns.md) | 切换到小黑身份；仅在需要时查看上游校准图。 |

角色设计的详细流程只在角色模式读取。日常内容生成使用已选角色，不重复询问画风或重新生成角色候选。

## 从口播形成镜头

按意思和情绪转折拆分，不按句号机械配图。每镜记录：

- 对应的原口播或文章段落、本镜唯一核心意思。
- 景别、主要物件与动作：环境、特写、机制、隐喻、数据载体或对比。
- 出场角色及其作用；设备、地图或数据镜头可以没有人物。
- 标注计划：准确文字、引线目标对象与部位、颜色、图内生成或后期叠加。
- 与前后镜头的衔接；需要时建议轻微推拉或平移。

文章分镜通常从 4–8 张起步；视频按口播长度和转折确定，用户指定的数量优先。没有录音时将时长标为估计，以实际录音重新对齐。环境、细节和观点图交替，保留必要停顿。

## 角色与解释性标注

- 默认中文、16:9 横版、白底细黑线和少量色块；用户的画幅、画风与角色选择优先。
- 有角色的镜头使用其身份档案及参考图，保持外貌、默认服装和线条一致；表情、动作和道具随当前口播变化。
- 角色参考图中的账单、计算器、文字和姿势不属于固定身份，不能自动复制到下一镜。
- 解释镜头通常安排 2–4 条必要的短标注，每条引线对应一个明确目标；纯场景镜头可无标注。
- 文字引线与表示流转的箭头分别设计，不用引线暗示未成立的因果关系。
- 图片负责解释，口播字幕、大段来源和主要统计数字优先后期叠加；用户要求写入图内时按已核准文字生成。
- 数据的对象、时间、分母或定义不清时，在分镜备注中标明，避免把宣传说法或待核验数字画成官方统计。

## 生成、检查与交付

使用当前环境可用的内置 `image_gen`，每张单独生成。用户明确要求生成时直接执行；整组任务不需要逐张重复确认。

第一次读取本地角色参考或编辑目标时，先查看图片，再交给图像工具。每张提示词说明参考图的具体角色、固定风格、本镜动作、准确标注、引线端点与字幕安全区。视频默认底部预留约 15%–20%；其余留白随镜头调整。

按 [QA](references/qa-checklist.md) 目视检查人物一致性、动作、文字、引线指向、语义与画幅，针对实际问题编辑或重生成。未经多镜头验证，不声称角色参考能保证整组绝对一致。

按用户指定的目录或当前项目的交付约定保存 PNG、分镜和提示词；无约定时使用 `assets/<topic-slug>-illustrations/`。保留原始生成文件，使用新文件名避免覆盖已有资产。交付说明图片用途、文件位置和需要后期补充的文字。
