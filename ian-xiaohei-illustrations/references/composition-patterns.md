# 分镜结构与原创隐喻

先选择最能承接当前口播的结构，再决定是否需要人物和标注。

| 结构 | 使用时机 | 表达方式 |
|---|---|---|
| 环境建立 | 交代生意或场所 | 店面、街角等清楚的远景，少量关键环境线索。 |
| 物件特写 | 解释动作或操作细节 | 聚焦投币口、滚筒、费用条目等一个部位。 |
| 机制与流向 | 解释钱或物如何流转 | 少量对象和明确方向；角色参与关键动作，或直接用物件解释。 |
| 前后对比 | 表现设想与现实、混乱与有序 | 保持可比较的对象，避免无关变化掩盖差异。 |
| 角色状态 | 讲经营者的体验 | 用姿势、视线和道具表达，不需要堆表情符号。 |
| 概念隐喻 | 解释成本、风险、时间等抽象关系 | 一个核心物件或物理动作，服务口播的意思。 |
| 地图或数据载体 | 交代规模、位置或数字口径 | 地理事实与示意图区分；百分比和出处可留后期叠加。 |
| 连续小场景 | 单个画面无法表达的过程 | 每个小场景一个动作；优先在视频里分镜，不把整段塞成一张拼图。 |

## 从观点构思画面

1. 找到口播里的动作或关系，例如流入、漏掉、积累、承担、修补、交换。
2. 选择能解释它的物件，例如收款盒、票据、秤、水管、钥匙。它必须与意思有关。
3. 需要人物时，让当前角色执行动作；不需要人物的特写和地图可省略角色。
4. 指出观众最容易忽略的条件，为它安排一条短引线标注。

隐喻不应制造事实错误。例如“店还开着”和“贷款违约”是不同观察对象，不画成同一分母的互补比例；地图上的几个图标不代表精确分布。

## 连续性与反复刻

同一片保持角色、设备和线条一致，通过景别与动作变化制造节奏。少量推拉和平移应沿信息顺序，不是无目的移动。

角色参考用于身份和画风，不带入其原来的道具、标注或场景。上游 [小黑校准图](../assets/examples/) 只在明确需要时查看，不能把其中的鱼、传送带或工具箱当成所有题目的固定构图。用户明确要求复刻时，按其指定保留构图。

洗衣店的“自动收钱”可以用角色接收金币的想象画面；“但账不是这么算的”可以让收款盒拉出长账单。这些是示例，后续主题重新根据口播构思。
